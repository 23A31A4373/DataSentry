#  DataSentry – CSV Data Quality Analyzer

**Your Data. Cleaner. Smarter.**

DataSentry is a Python-based web application that helps users analyze, identify, and improve the quality of CSV datasets.

##  Features

- **Dataset Overview:** View total rows, columns, and duplicate records.
- **Data Quality Score:** Get an overview of dataset quality.
- **Dataset Preview:** View uploaded CSV data.
- **Column Information:** Understand column names and data types.
- **Missing Value Analysis:** Identify missing values in each column.
- **Descriptive Statistics:** Generate statistical summaries.
- **Data Cleaning:** Remove duplicate rows and handle missing values.
- **CSV Upload:** Upload your own CSV datasets.

##  Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib

##  Installation and Setup

1. Clone this repository:

   `git clone https://github.com/23A31A4373/DataSentry.git`

2. Navigate to the project folder:

   `cd DataSentry`

3. Install the dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`
